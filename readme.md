# 🖤 BLACKVEIL SHELL

A web-based **File Manager & Command Shell** built with PHP and designed with a cyberpunk dark theme.

This project was created for learning, development, and experimentation with PHP-based web applications.

- 🔐 Admin Login
- 📁 File Manager
- 📂 Folder Navigation
- ⬆️ File Upload
- 📄 Create File
- 📁 Create Folder
- ✏️ Rename
- 📝 Edit File
- 🗑️ Delete File
- 🔢 CHMOD
- 💻 Terminal Interface
- 🌨️ Snow Effect
